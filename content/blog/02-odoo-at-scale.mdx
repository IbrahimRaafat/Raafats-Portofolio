Odoo is fantastic until you try to run it like production software.

For **Maz Mrkt** we needed Odoo 18 to behave like a real backend: fast, observable, and deployable without SSH-ing into a single long-lived VM and praying.

### Stack

- **EC2 + ALB + AutoScaling** — Odoo behind Gunicorn, not the built-in server.
- **RDS Postgres** — separate from the app host, with PITR.
- **CloudFront + ACM** — TLS termination and edge caching for static + API.
- **Systemd + blue/green** — new version boots on `:8070`, health-checks, then LB swaps.

Two wins that mattered more than infra:

1. **ORM automations in Python** that cut manual order routing by 50%. No more spreadsheet-to-Odoo copy paste.
2. **Shopify ↔ Odoo sync** as an idempotent queue (n8n + webhooks) instead of nightly CSV dumps.

Uptime +40%, p95 latency -30% — but the real win is that a second engineer can now deploy on day one.
